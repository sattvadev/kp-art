# AI sketch model

`opensketch.onnx` is the "OpenSketch" style model from **Informative Drawings: Learning to Generate Line Drawings
that Convey Geometry and Semantics** by Caroline Chan, Frédo Durand and Phillip Isola (CVPR 2022),
https://github.com/carolineec/informative-drawings — MIT License, Copyright (c) 2022 Caroline Chan
(see `LICENSE-informative-drawings`).

ONNX conversion from https://huggingface.co/backnotprop/informative-drawings-image-to-opensketch-onnx (MIT),
SHA-256 `4ed7a5c28aadf8655fbbafe0ed5340be2beab9ad1baa84894bbabeb5d5c9bb4b`, 17,198,443 bytes.

It runs in the browser with onnxruntime-web; photos never leave the device.
